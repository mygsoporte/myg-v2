Despacho jurídico · Barcelona

HelpDesk y administración de sistemas para un despacho de abogados

Un departamento IT externo con un alcance claro, para que el despacho se centre en sus clientes.

  • MGCare
  • Ciberseguridad
  • Microsoft 365
Despacho jurídico

El reto

El despacho combina un entorno híbrido —directorio local sincronizado con Microsoft Entra ID, servidores virtualizados, escritorio remoto y doble factor— y necesitaba un único proveedor responsable de la infraestructura y del soporte a los usuarios.

Qué hicimos

  • Documento de alcances que define con precisión qué cubre el servicio y qué queda fuera, como las aplicaciones de negocio de terceros.
  • HelpDesk para los usuarios y administración de servidores, identidad, acceso remoto y firewall.
  • Plan para incorporar la monitorización centralizada como proyecto independiente.

Resultados

  • Un interlocutor único para la infraestructura y los usuarios.
  • Responsabilidades claras entre el despacho, M&G y los proveedores de software.
  • Base documentada para evolucionar el entorno con seguridad.

Tecnologías

  • Active Directory
  • Escritorio remoto
  • Doble factor
  • Virtualización
